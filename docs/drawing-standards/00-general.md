# 00 — General Drawing Standards

Use these conventions on every sheet unless project-specific standards override.

## Sheet Sizes & Title Block

| Size | Dimensions | Typical use |
|------|-----------|-------------|
| ANSI A | 8.5" × 11" | Detail-only handouts |
| ANSI B | 11" × 17" | Small residential projects |
| ARCH C | 18" × 24" | Standard residential |
| ARCH D | 24" × 36" | Custom homes, additions |

**Title block** (right side or bottom): project name, address, owner, sheet title, sheet number, scale, date, revision block, designer name/seal area, north arrow on plans.

## Sheet Numbering

| Prefix | Discipline |
|--------|-----------|
| G | General (cover, code summary, abbreviations) |
| A | Architectural |
| S | Structural |
| C | Civil / site |
| M / P / E | Mechanical / Plumbing / Electrical |

Residential add/remodel minimum sheet list:
- G-001 Cover, code summary, sheet index
- A-101 Site plan
- A-201 Floor plan(s)
- A-301 Elevations (typically all four)
- A-401 Building section(s)
- A-501 Wall sections & details
- S-101 Foundation plan
- S-201 Framing plan(s)
- S-501 Structural details

## Scales

| View | Common scale (imperial) | Metric equivalent |
|------|------------------------|-------------------|
| Site plan | 1" = 10' or 1" = 20' | 1:100 / 1:200 |
| Floor plan, foundation, framing | 1/4" = 1'-0" | 1:50 |
| Wall section | 3/4" = 1'-0" | 1:20 |
| Detail | 1-1/2" = 1'-0" or 3" = 1'-0" | 1:10 / 1:5 |
| Elevation | 1/4" = 1'-0" | 1:50 |

## Line Weights (printed)

| Weight | mm | Use |
|--------|-----|-----|
| Fine | 0.13 | Hatching, dimension lines, leader lines |
| Thin | 0.18 | Hidden lines, centerlines |
| Medium | 0.25 | Object lines (most building elements) |
| Heavy | 0.35 | Section cuts, profile of cut elements |
| Extra heavy | 0.50–0.70 | Border, title block, profile of building outline |

## Dimensioning

- Dimension to face of stud or face of concrete for framing; to face of finish only when finish thickness is critical.
- Stack dimension strings: overall, then column lines/bays, then openings.
- Round to 1/8" minimum; never dimension to fractional inches finer than 1/16".
- Show one dimension once. Never double-dimension a single distance.
- Tie all dimensions to a clear datum (property line, building corner, gridline).

## Common Symbols

| Symbol | Meaning |
|--------|---------|
| Circle with letter (above line) over number (below) | Detail callout — letter = detail, number = sheet |
| Hexagon with note number | Keynote reference |
| Bubble with grid letter or number | Column/grid line |
| Arrow with section letter and sheet number | Section cut |
| North arrow + true/project north designation | Orientation |

## Required Notes Block (residential)

Every drawing set should carry:

1. **Code basis** — "Construction shall conform to IRC 2021 as amended by [jurisdiction]."
2. **Design loads** — live, dead, snow, wind speed, seismic design category, frost depth.
3. **Soils assumption** — "Assumed allowable soil bearing 1,500 psf per IRC Table R401.4.1, to be verified by contractor at footing excavation."
4. **Material grades** — concrete f'c, rebar grade, lumber species/grade, fastener types.
5. **Fastener corrosion** — "All fasteners and connectors in contact with preservative-treated lumber shall be hot-dipped galvanized (ASTM A153) or stainless steel."
6. **Contractor responsibilities** — verify field conditions, locate utilities, comply with OSHA.
7. **AHJ verification** — "Final design subject to review by Authority Having Jurisdiction."

## Schedules That Must Appear

- **Fastener / connector schedule** — every connector model number (e.g., Simpson LUS28, LSSU210) with quantity and location reference.
- **Lumber schedule** — species, grade, treatment, size by tag.
- **Concrete schedule** — f'c at 28 days, slump, air entrainment if exposed.
- **Rebar schedule** — bar size, grade, lap length, cover.

## Drawing Hierarchy for Construction Plans

Every element gets at least:
1. A **plan view** (where it sits).
2. A **section** (what's inside vertically).
3. **Details** at critical connections (where things meet).
4. An **elevation** if appearance-critical.

If a detail cannot be drawn at 1-1/2" = 1'-0" or larger, it's probably oversimplified.
